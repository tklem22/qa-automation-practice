# QA Automation Practice

[![Saucedemo Playwright tests](https://github.com/tklem22/qa-automation-practice/actions/workflows/saucedemo-tests.yml/badge.svg?branch=main)](https://github.com/tklem22/qa-automation-practice/actions/workflows/saucedemo-tests.yml)

A portfolio project showing end-to-end test automation with Playwright and TypeScript, run automatically on every push with GitHub Actions.

- **19 tests** against [saucedemo.com](https://www.saucedemo.com), a public practice store (no real accounts or data)
- **Page-object structure** for maintainable selectors and actions
- **CI pipeline** that runs the suite and publishes an HTML report
- **7 documented bugs** found on the site's deliberately broken demo users

Start here: [saucedemo-playwright/](saucedemo-playwright/README.md)
